## Новая функциональность

Проект дополнен следующими возможностями:

- **Поиск транзакций** — функция `process_bank_search(data, search)` из модуля `src.search` находит операции, в описании которых встречается заданная строка. Поиск использует библиотеку `re`, не зависит от регистра и корректно обрабатывает спецсимволы.
- **Подсчёт категорий** — функция `process_bank_operations(data, categories)` из модуля `src.categories` считает количество операций в каждой из переданных категорий с помощью `Counter` из библиотеки `collections`.
- **Интерфейс пользователя** — функция `main()` из модуля `src.main` связывает всю логику: выбор источника данных (JSON/CSV/XLSX), фильтрацию по статусу, сортировку по дате, отбор рублёвых операций и поиск по слову в описании.

### Запуск

python -m src.main
