# Bank Widget Project

Проект «Банковские виджеты»: функции маскировки реквизитов карт и счетов,
форматирования дат и обработка транзакций.

## Установка

1. Клонируйте репозиторий:
   git clone <ссылка на ваш репозиторий>
2. Установите зависимости через Poetry:
   poetry install
3. Активируйте виртуальное окружение:
   poetry shell

## Использование

Проверить работу функций можно запуском скрипта:

python check.py

Основной функционал импортируется из модуля `src.widget`:

- `mask_account_card` — маскирует номер карты или счёта;
- `get_date` — форматирует дату в читаемый вид.

## Тестирование

Проект покрыт pytest-тестами. Запуск:

pytest

## Линтинг и типизация

flake8 src tests main.py check.py --max-line-length=119
mypy src tests main.py check.py
